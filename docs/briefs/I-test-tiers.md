# Silo I: Test tiers

**Wave 1** for the golden tier. **Wave 3** for the agent evaluation tier, which measures everything else and so runs last.

**Specs:** `10` (all), `12` (*Metrics and evals*), `11` (scoped-session eval premise).

## Goal

Build the two test tiers that don't exist yet: deterministic golden tests in CI, and the opt-in agent benchmark that tests the project's core claim (that palette sheets and perception tools help an agent build better for fewer tokens).

## Deliverables

**Wave 1: golden tier (`test/golden/`)**
1. **Synthetic instance:** hand-made jars with original test textures, covering VFS layer order, blockstate variants and multipart, parent chains, and the colour index (`10`). Generated by a script in `scripts/` so it's reviewable and reproducible.
2. **Format round-trips** for `.schem` v2/v3, `.bp` and `.nbt`, including unknown blocks and block-entity NBT. Add `.litematic` when silo H lands it.
3. **Render snapshots** of fixtures against golden PNGs within a perceptual tolerance, with an update command for intentional changes.
4. **Sheet determinism:** same input, same cell map.
5. **Analysis goldens** from silo B's fixture buildings once `analyze` merges.
6. Wire the golden tier into `npm test` and keep the whole run fast enough for CI.

**Wave 3: agent evaluation tier (`test/eval/`)**
7. **Runner** on the Claude Agent SDK, default model `claude-sonnet-5-5` (configurable), driving the MCP server and recording transcript, tool calls, tokens and wall time.
8. **Benchmark set** of about 15–25 prompts from simple to architectural, with seed documents where needed.
9. **Scoring:** automatic checks written with the `analyze` API (storeys, door facade, watertight roof, no floating blocks, palette roles, bounding box); a model-graded rubric over final renders with fixed judge prompts; cost (total tokens, image tokens, tool calls).
10. **Ablations** with features switched off (no `analyze`, no components, text-only, images-only, no palette sheets). This needs a server option to hide tools, so add one.
11. **Scoped-session comparison** (`10`, `11`): monolithic versus delegated runs on large builds, plus fork rates on small prompts to calibrate the delegation threshold. Join the server's event log (silo G) with the SDK transcript on tool-call order for token counts.
12. Results in `test/eval/results/<date>-<git-sha>.json` plus a summary table, compared against the last baseline. `npm run eval` needs `ANTHROPIC_API_KEY` and never runs in CI.

## Files you own

- New: `test/golden/**`, `test/fixtures/**`, `test/eval/**`, fixture-generation scripts in `scripts/`.
- `vitest.config.ts`, the `scripts` section of `package.json`.

## Done when

- `npm test` runs tiers 1 and 2. A deliberate one-block change to a renderer or format breaks a golden test.
- `npm run eval` completes a reduced suite of three prompts end to end and writes a results file.
- `10` gains an *Implementation status* table.
