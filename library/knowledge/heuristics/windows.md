summary: Spacing and aligning openings into bays so facades read as ordered rather than random.
---
Suggestions, with the reasons behind them.

## Bays
- **Divide the facade into equal bays** (often 3–4 blocks wide) and put one opening per bay. Why: a repeated interval is what the eye reads as "designed"; random spacing reads as unfinished.
- **Keep the wall between windows at least as wide as a window.** Narrower piers look weak; much wider ones make the building look closed.
- **Odd numbers of bays** (3, 5, 7) give a central bay for the door or a feature.

## Alignment
- **Stack windows vertically** across storeys. Why: misaligned windows break the bay structure, unless the asymmetry is the point (a stair window, a later extension).
- **Align window heads with the door head** on the ground floor.
- Upper storeys can have **smaller or equal windows**, rarely larger: it keeps the visual weight at the bottom.

## Shape and depth
- **Recess glass by one block** (or use panes/trapdoors set back) instead of placing it flush. See heuristics/depth.
- A sill (slab or upside-down stair) below and a lintel (different material) above each opening turns a hole into a window.
- Tall narrow windows read as older or more formal; wide ones read as modern or commercial.

## Exceptions worth making
- A single big feature window (rose window, shop front, bay window) can break the rhythm when everything else keeps it.
